# Filament Meter 0.1.0-beta.2

This beta adds multi-printer monitoring, per-printer cost records, model previews, and experimental camera-based failure detection.

## Changes

- Save multiple printers with separate LAN credentials and pricing; discover printers on the local network.
- See all saved printers on Meter and switch the active printer in Printer. Background MQTT monitoring continues for configured printers.
- Show the current print's model thumbnail from its exact 3MF file, with tap-to-enlarge on Meter and Printer.
- Add H2S artwork and model identification.
- Record observed print history with estimated material costs using saved price snapshots.
- Track dated waste adjustments for purging, failed prints, and scraps, with per-printer breakdowns.
- Add experimental on-device YOLO print watch for spaghetti, lifting/warping, and layer shifts, with confidence controls and repeated-frame confirmation.
- Overlay labeled detection boxes and confidence on the camera preview, including zoom, fit/fill, and fullscreen. Stale boxes expire automatically.
- Add different notification sounds and vibration patterns for each failure type, independent cooldowns, and test/customization controls in Setup.
- Add sound and vibration to printer-event alerts while keeping routine progress silent.
- Route notification and widget actions to the correct printer; preserve existing connection settings during profile migration.

## Validation

- Signed release build, 31 release unit tests, and Android lint passed.
- Device checks covered profile migration, cost separation, model inference, overlay rendering, and notification channel delivery.
- Retrieved the actual active print thumbnail from a P1S and checked its display and enlarged view on Pixel 9 Pro Fold.
- The development build was installed on Pixel Fold, Pixel 9 Pro Fold, Samsung Galaxy tablet, and Razer Edge. Installation on all four does not imply every feature was tested on every device.

## Beta limitations

- Failure detection is experimental, warns only, and never automatically pauses or stops a printer. Lifting accuracy on P1S is not established.
- Background camera/YOLO monitoring and the current wake-lock behavior can use noticeable battery. Battery drain per hour has not been measured.
- Print costs are estimates from manually entered sliced grams and spool prices; electricity and machine costs are excluded. History begins with prints observed by the app.
- Model previews require LAN file access and a usable plate thumbnail. Multi-plate files without an identifiable active plate, plain G-code jobs, and archives over 64 MB can show preview unavailable.
- Camera streaming is supported for the existing P1/A1 LAN camera protocol; H2S artwork support does not add H2S video streaming.
- Android notification permission, volume, channel settings, silent mode, Do Not Disturb, and notification cooldown affect alerts.

## Installation

Android 8.0 or newer. The signed release uses the same certificate as `0.1.0-beta.1` and can update that release without uninstalling. Development APKs use a different signing certificate and cannot be replaced in-place by this release; do not uninstall them unless you are prepared to reconfigure local settings and lose their app-local records.
